# 12주 커리큘럼 — 텍스트판

「두 번째 명함」 · 은퇴·은퇴예정 사무직 대상 AI 활용 실무 과정
주 1회 2시간 × 12주 = 총 24시간 · 정원 20명 · 조교 2명

전체 설계 근거와 삽화는 [강의계획서](https://heekeunlee.github.io/for_senior/) 참고.

## 설계 원칙 5

1. **설치 금지, 전 과정 브라우저에서** — 계정 가입은 개강 전 사전 OT에서 완료
2. **코드는 보되 쓰지 않는다** — 타이핑 없음. 말로 고치는 경험만 반복
3. **첫 주제는 반드시 본인의 것** — 예제 데이터 금지
4. **에러 대응을 정식 교과로** — 5주차를 통째로 배정
5. **동년배가 옆에 있어야 한다** — 조교는 동년배 또는 앞 기수 수료생

### 이탈 위험이 솟는 네 지점과 방어 장치

| 주차 | 원인 | 방어 |
|---|---|---|
| 1주 | 계정 가입 장벽 | 사전 OT에서 계정 개설 완료. 예비 계정 5개 확보 |
| 5주 | 첫 에러 경험 | 5주차 자체가 에러 대응 전용 회차 |
| 7주 | 내 데이터 준비 실패 | 6주차 종료 시 지참 안내 + 조교 사전 점검 |
| 10주 | 트랙 선택 부담 | 9주차에 1:1 사전 상담으로 확정 |

## 1단계 · 즉시 효용 (1–3주)

> 목표 감정: **"이걸 진작 알았으면"**

### 1주차 — AI에게 제대로 시키는 법 + 엑셀·문서 실무에 얹기
- 지시문 쓰는 법, 파일 첨부, 결과 검증
- **본인이 실제로 막혔던 엑셀 문제 3개를 지참** → 그 자리에서 해결
- 결과물: 내 엑셀 문제 3건 해결 기록

> 이 회차의 목적은 엑셀 교육이 아니라 **신뢰 획득**이다.
> 수강생이 강사보다 엑셀을 잘하는 상황이 반드시 발생하며, 그것이 정상이다.
> 화법은 "제가 가르쳐 드립니다"가 아니라 **"여러분 실력에 AI를 붙이면 어떻게 되는지 보시죠"**.

### 2주차 — 긴 문서 다루기
- 보험증권, 아파트 관리규약, 계약서, 건강검진 결과지 → 요약·비교·독소조항 찾기
- **AI 환각과 검증법을 여기서 명시적으로 교육**
- 결과물: 내 보험 중복보장 점검표

### 3주차 — 이미지·영상 + 디지털 안전
- 전반 80분: 행사 초대장, 포스터 제작
- 후반 40분: **딥페이크 보이스피싱 실습** — 목소리 복제를 직접 시연하고 대응법 교육
- 결과물: 가족 행사 초대장 / 안전 수칙 카드

## 2단계 · 말로 앱 만들기 (4–6주)

> 목표 감정: **"내 앱이 생겼다"**

### 4주차 — 대화만으로 웹앱 만들기
- 바이브 코딩 첫 경험. 복약 알리미 또는 가계부 앱 중 택1
- 코드는 화면에 보여주되 타이핑 없음
- 결과물: 동작하는 내 첫 앱

### 5주차 — 고치기와 에러 대응 ⚠️ 이탈 방어 회차
- **일부러 앱을 망가뜨린 뒤** AI에게 고쳐 달라고 요청
- 에러 메시지를 그대로 복사해 붙이는 훈련 반복
- 결과물: 개선된 앱 + 공유 링크

> **이 회차는 절대 빼지 말 것.** 완주율을 결정하는 단일 최대 변수다.
> "에러 = 내가 못한 것"이 아니라 "에러 = 붙여넣고 물어보면 되는 것"으로 각인시키는 것이 목적.

### 6주차 — 계산기형 앱 만들기
- 연금 개시 시점별 수령액 비교, 은퇴 후 현금흐름 시뮬레이터
- 숫자를 다뤄본 사무직 경험이 그대로 활용되는 회차
- 결과물: 내 연금 시뮬레이터
- **수업 종료 시 7주차용 데이터 지참 안내**

## 3단계 · 데이터와 대시보드 (7–9주)

> 목표 감정: **"내 데이터가 그림이 됐다"**

### 7주차 — 내 데이터 확보와 정리
- **첫 20분: 개인정보 마스킹 작업을 조교와 함께 수행** (아래 규칙 참조)
- 카드사 내역 내려받기, 검진 결과 입력, 회비 장부 정리
- 결과물: 정제된 내 데이터셋

### 8주차 — 대시보드 만들기 ①
- 무엇을 볼 것인가(지표 설계) → 어떤 그림으로 볼 것인가(차트 선택)
- 지출 또는 건강 중 택1
- 결과물: 1차 대시보드

### 9주차 — 대시보드 만들기 ② + 트랙 사전 상담
- 데이터 갱신과 공유 설정
- **후반 30분: 조교가 1:1 트랙 상담** → 10주차 선택 부담 사전 해소
- 결과물: 완성 대시보드 링크 + 트랙 확정

## 4단계 · 트랙별 개인 프로젝트 (10–12주)

> 목표 감정: **"내 이름의 결과물"**

### 트랙 4종

| 트랙 | 최종 결과물 |
|---|---|
| **제2커리어** | 컨설팅 소개 웹페이지 + 경력기술서 + 나만의 AI 강의조교 |
| **자산관리** | 연금·지출·자산 통합 대시보드 |
| **기록·유산** | AI 인터뷰 자서전 초고 + 가족 아카이브 웹페이지 |
| **모임·창업** | 동호회 총무 시스템 또는 소상공인 매출 대시보드 |

트랙별 최소 인원 3명. 미달 시 인접 트랙 병합.
**자산관리 트랙에 쏠릴 가능성이 가장 높으므로 금융 배경 강사 또는 외부 자문을 사전 배정.**

### 10주차 — 기획과 재료 준비
트랙별 분반. 무엇을 만들지 확정하고 필요한 자료 수집. 결과물: 프로젝트 기획서 1장

### 11주차 — 제작과 상호 피드백
제작 집중. 중간에 짝끼리 서로의 결과물을 써 보고 고칠 점을 말해주는 시간 확보. 결과물: 프로젝트 초안

### 12주차 — 발표회 🎓
- 1인당 5분 발표
- **그 자리에서 가족·지인에게 결과물 링크를 실제로 전송하는 것까지가 커리큘럼**
- 시상은 순위가 아니라 부문별(가장 실용적인 / 가장 따뜻한 / 가장 뜻밖의)
- 업로드 자료 삭제 방법 안내
- 결과물: 완성 결과물 + 수료증 + 전송 완료

## 1회차 120분 표준 배분

```
0–10분     지난주 결과 공유       ← 결석자를 다시 나오게 하는 장치
10–25분    오늘 만들 것 시연
25–85분    직접 실습 (60분)       ← 절반은 반드시 만드는 시간
85–105분   막힌 것 해결
105–120분  정리 + 다음주 재료 안내
```

**설명은 최대 25분.** 출석 체크로 시작하지 말 것 — 결석이 창피해져 그대로 이탈한다.

## 개인 데이터 취급 규칙 (7주차 전 필수 고지)

**업로드 금지** — 주민등록번호, 계좌번호, 카드번호 전체, 비밀번호, 타인의 개인정보

**업로드 허용** — 금액·날짜·항목명만 남긴 내역, 수치만 남긴 검진 결과

- 파일 업로드 전 마스킹 작업을 조교와 함께 수행
- 타인 데이터(회비 장부 등)는 이름을 이니셜로 치환
- 서면 동의서 수령
- 과정 종료 시 삭제 방법 안내

## 수료 기준

- 12회 중 **8회 이상 출석**
- 최종 프로젝트 결과물 **1건 제출**
- 발표회 참여

**등급·석차·점수는 매기지 않는다.** 시험 스트레스는 이 대상층에서 가장 확실한 이탈 요인이다.

## 8주 축약안

예산이 8주뿐이라면:

- 3단계를 2주로 압축 (7·8주차 통합)
- 4단계를 1주 제작 + 1주 발표로 축소
- 총 16시간 → 국내 공공과정 표준 범위에 진입

**절대 빼면 안 되는 것**
1. 1주차 엑셀 회차 — 이 대상층의 신뢰를 얻는 유일한 회차
2. 5주차 에러 대응 — 완주율을 결정
3. 마지막 발표회 — 재등록과 입소문을 결정
