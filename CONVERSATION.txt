  1. 교육 방향 상담
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛


  질문
  ────────


  ▌ 은퇴를 앞두거나 은퇴한 직장인들에게 AI교육을 하려고해. 전문적인 개발자가
  ▌ 되는 교육은 아니고 AI를 활용한 앱, 대쉬보드 만들기 정도의 성취감을 느낄수
  ▌ 있는 교육을 하는게 목표야. 흥미를 떨어뜨리지않는 것이 중요할것 같아.
  ▌ 어떻게 생각해? 교육을 어떤것들을 하면 좋을까?


  답변
  ────────


  좋은 방향이라고 생각합니다. 다만 이 대상층에서 성패를 가르는 건 커리큘럼
  내용보다 "첫 30분 안에 내 결과물이 화면에 뜨는가" 입니다. 개념부터 가르치면
  3주차에 절반이 빠집니다.


  [ 설계 원칙 (커리큘럼보다 중요) ]


  1. 설치 금지, 전부 브라우저에서
  파이썬 설치, VS Code, 터미널, 깃 — 하나라도 들어가면 그날 강의는 설치
  지원으로 끝납니다. 웹에서 로그인만 하면 되는 도구로 전 과정을 짜세요.

  2. 코드를 "보긴 하되 쓰지는 않는다"
  AI가 만든 코드를 보여주되 타이핑은 시키지 마세요. 오타 하나로 자존감이
  무너집니다. 대신 "이 부분 색깔을 파랗게 바꿔줘" 처럼 말로 수정하는 경험을
  반복시키면, 자기가 통제하고 있다는 감각이 생깁니다.

  3. 첫 주제는 반드시 "본인의 것"
  샘플 데이터로 만든 대시보드는 아무 감흥이 없습니다. 본인 가계부, 혈압·복약
  기록, 동호회 회비 장부, 손주 사진, 산행 기록 — 자기 데이터가 들어가는 순간
  몰입도가 달라집니다.

  4. 에러를 "학습 내용"으로 정식 편입
  화면이 하얗게 뜨는 순간이 최대 이탈 지점입니다. 1주차에 아예 일부러 에러를
  내고 AI에게 고쳐달라고 하는 실습을 넣으세요. "에러 = 실패"가 아니라 "에러 =
  붙여넣고 물어보면 되는 것"으로 각인시키는 게 핵심입니다.

  5. 마지막은 무조건 발표회
  결과물 링크를 카톡으로 가족·친구에게 보내는 것까지가 교육입니다. "내가 만든
  걸 딸한테 보냈더니 놀라더라" — 이게 재수강과 입소문을 만듭니다.


  [ 커리큘럼 제안 (8주 × 2시간) ]


  · 1
      주제          : AI와 대화하기 + 계정 세팅
      그날의 결과물 : 내 소개 페이지 (링크로 공유)

  · 2
      주제          : 문서·자료 다루기 (PDF 요약, 번역, 메일 초안)
      그날의 결과물 : 관심 분야 요약 리포트

  · 3
      주제          : 이미지·영상 만들기
      그날의 결과물 : 가족 행사 초대장 / 동호회 포스터

  · 4
      주제          : 말로 앱 만들기 ①
      그날의 결과물 : 개인 가계부 앱 or 복약 알리미

  · 5
      주제          : 말로 앱 만들기 ② — 수정과 에러 대응
      그날의 결과물 : 4주차 앱 개선 + 지인에게 배포

  · 6
      주제          : 표 데이터 다루기 (스프레드시트 + AI)
      그날의 결과물 : 내 지출/건강 데이터 정리

  · 7
      주제          : 대시보드 만들기
      그날의 결과물 : 자기 데이터 시각화 대시보드

  · 8
      주제          : 나만의 AI 도우미 + 발표회
      그날의 결과물 : 개인 맞춤 챗봇 + 전체 발표


  도구 스택: Claude(Artifacts로 앱을 만들고 바로 링크 공유) 또는
  ChatGPT/Gemini 캔버스 계열 + 구글 스프레드시트. 대시보드는 굳이 코드 안 가고
  Looker Studio로 빼도 됩니다. 도구는 최대 3개까지만 쓰세요.


  [ 잘 먹히는 주제 ]


  · 건강: 혈압·혈당·체중 기록 대시보드, 복약 시간표
  · 돈: 연금 수령액 시뮬레이터, 지출 분석, 보험 약관 요약
  · 관계: 손주 사진첩 웹페이지, 가족 행사 D-day 페이지, 동창회 명부
  · 취미: 등산·자전거 기록, 텃밭 일지, 독서 기록
  · 재취업: 이력서·자소서 다듬기, 강의안 만들기, 블로그 자동 초안

  여기에 디지털 안전 한 꼭지는 꼭 넣으시길 권합니다. AI 목소리 복제·딥페이크
  보이스피싱이 이 연령대 실제 피해로 이어지고 있어서, "AI가 이런 것도 되니까
  이런 전화는 의심하라"는 내용이 실용적 가치가 큽니다.


  [ 운영 디테일 ]


  · 조교 비율: 수강생 6~8명당 1명. 예산상 가장 큰 항목인데 여기서 아끼면 전부
    무너집니다.
  · 계정은 사전에: 휴대폰 인증, 해외 결제카드 등록에서 1주차가 다 날아갑니다.
  · 화면: 강사 화면 폰트 크게, 커서 강조 켜기. 수강생 브라우저도 첫날 확대
    배율 설정.
  · 2인 1조: 옆사람에게 물어볼 수 있는 구조 + 사회적 동기.
  · 복습 자료는 종이: 스크린샷 큼직하게 넣은 유인물이 온라인 자료보다 훨씬 잘
    쓰입니다.
  · 매주 결과물 링크 아카이브: 8주차에 쌓인 걸 보는 게 성취감의 핵심.


  [ 미리 감안할 함정 ]


  · 무료 티어 한도: 4~7주차 실습 도중 사용량 제한에 걸리면 수업이 멈춥니다.
  · AI 도구 UI가 자주 바뀝니다: 스크린샷 기반 교재는 몇 달이면 안 맞습니다.
  · 환각: 건강·연금·세금 질문이 반드시 나옵니다. "AI 답변은 확인이 필요하다"를
    2주차에 명시적으로 다뤄야 합니다.

  1부. 잘 먹히는 주제 확장판
  ──────────────────────────


  [ A. 돈 — 가장 강한 동기 ]


  · 연금 3층(국민·퇴직·개인) 수령 시점별 시뮬레이터
  · 은퇴 후 현금흐름 대시보드 — 몇 살까지 버티는지 시각화
  · 카드사 CSV 내려받아 지출 자동 분류 + 월별 추이 대시보드
  · 건강보험 지역가입자 전환 시뮬레이션 (퇴직 직후 최대 관심사)
  · 보험증권 여러 장 넣고 중복 보장·보장 공백 점검표
  · 배당 포트폴리오 + 배당금 입금 캘린더
  · 상속·증여 시나리오 정리 → 세무사 상담용 질문지
  · 주택연금 vs 전세 vs 매도, 3안 비교표


  [ B. 건강 — 두 번째로 강한 동기 ]


  · 혈압·혈당·체중·걸음수 기록 앱 + 추이 그래프
  · 복약 스케줄러 (다약제 복용자 많음)
  · 건강검진 결과지 5년치 넣고 수치 시계열 비교
  · 병원 가기 전 증상·질문 정리 도우미
  · 부모님(80~90대) 돌봄 기록 형제 공유 시트
  · 등산·자전거·수영 기록 대시보드


  [ C. 경력 자산화 — 이 층에만 있는 주제, 반응 최고 ]


  · 30년 경력을 경력기술서·컨설팅 소개서로 재구성
  · 강의안 만들기 — 은퇴 사무직의 상당수가 강사·멘토로 갑니다
  · 내 업무 노하우를 전자책/PDF 매뉴얼로
  · AI와 모의면접 (재취업 준비)
  · 자격증 공부 도우미 — 요약, 예상문제 생성, 오답노트
  · 개인 브랜드 원페이지 웹사이트 (명함 QR로 연결)
  · 창업 아이템 시장조사 + 사업계획서 초안


  [ D. 소상공인·부업 실무 ]


  · 매출·재고 관리 시트 + 사장님 대시보드
  · 메뉴판, 전단지, 간판 시안 (이미지 생성)
  · 블로그·인스타 콘텐츠 초안 자동화
  · 리뷰 답글, 고객 응대 문구 세트
  · 상권·경쟁점 조사 자료 정리


  [ E. 사회활동 — 은퇴자 정체성의 핵심 ]


  · 동호회·동창회 회비 장부 + 정산 대시보드 (총무 맡은 분 많음)
  · 참석 집계, 공지문, 회원 명부 자동화
  · 여행 계획표 — 일정·예산·지도·체크리스트 한 페이지
  · 여행 사진 → 여행기 웹페이지 (카톡 공유)
  · 봉사단체 활동 기록, 종중·문중 자료 정리


  [ F. 기억과 유산 — 정서적 임팩트가 가장 큰 영역 ]


  · AI가 인터뷰하며 쓰는 자서전 — 매주 질문 받고 답하면 원고가 쌓임
  · 부모님 구술 녹음 → 텍스트 → 책 형태로
  · 손주 사진첩 웹페이지, 가족 연대기
  · 오래된 흑백사진 복원·컬러화
  · 어머니 레시피 아카이브


  [ G. 사무 스킬 → AI 전환 (이분들의 홈그라운드) ]


  · 엑셀 함수·피벗·매크로를 AI에게 시키기 — 첫 주에 "이거 왜 이제 알았지" 반응
  · 아파트 관리규약·계약서·약관 요약과 독소조항 찾기
  · 회의 녹음 → 회의록 자동 정리
  · 공문·메일·민원 답변 작성
  · PPT 초안 생성, 장표 구조 잡기
  · 번역 (해외 자녀, 직구, 여행)


  [ H. 취미·자기실현 ]


  · 유튜브 기획·자막·썸네일 / 블로그 자동화
  · AI로 그림 그리기, 음악 만들기
  · 텃밭 일지 + 작물 캘린더
  · 시집·에세이 만들어 자비출판
  · 반려동물 건강 기록


  [ I. 디지털 안전 — 선택 아닌 필수 ]


  딥페이크 보이스피싱, AI 투자사기, 개인정보 입력 금지 원칙, 환각 검증법,
  구독료 관리.


  2부. 다시 짠 커리큘럼 (12주 × 2시간)
  ────────────────────────────────────


  [ 1단계 · 즉시 효용 (1~3주) — "이거 진작 알았으면" ]


  · 1
      내용   : AI 제대로 시키는 법 + 엑셀·문서 실무에 얹기
      결과물 : 내 엑셀 문제 3개 AI로 해결

  · 2
      내용   : 긴 문서 다루기 — 약관·규약·검진결과·보험증권
      결과물 : 내 보험 중복보장 점검표

  · 3
      내용   : 이미지·영상 + 디지털 안전
      결과물 : 행사 초대장 / 딥페이크 실습


  ▌ 1주차 엑셀이 핵심입니다. 자기가 잘 아는 영역에서 AI의 위력을 먼저 체감해야
  ▌ 이후 낯선 걸 받아들입니다.


  [ 2단계 · 말로 앱 만들기 (4~6주) — 성취감의 정점 ]


  주차   내용                                     결과물
  ────   ──────────────────────────────────────   ─────────────────────────
  4      대화만으로 웹앱 만들기                   복약 알리미 or 가계부 앱
  5      수정·에러 대응 (일부러 에러 내보기)      4주차 앱 개선 + 링크 배포
  6      계산기형 앱 — 연금·현금흐름 시뮬레이터   내 연금 수령 시뮬레이터


  [ 3단계 · 데이터와 대시보드 (7~9주) — 사무직 경험이 빛나는 구간 ]


  · 7
      내용   : 내 데이터 확보·정리 (카드내역, 검진결과, 회비장부)
      결과물 : 정제된 내 데이터셋

  · 8
      내용   : 대시보드 만들기 ① — 지표 설계와 차트
      결과물 : 지출 or 건강 대시보드

  · 9
      내용   : 대시보드 만들기 ② — 자동 갱신·공유
      결과물 : 완성 대시보드 링크 공유


  [ 4단계 · 트랙별 개인 프로젝트 (10~12주) ]


  트랙        최종 결과물
  ─────────   ───────────────────────────────────────────────────────
  제2커리어   컨설팅 소개 웹페이지 + 경력기술서 + 나만의 AI 강의 조교
  자산관리    연금·지출·자산 통합 대시보드
  기록·유산   AI 인터뷰 자서전 초고 + 가족 아카이브 웹페이지
  모임·창업   동호회 총무 시스템 or 소상공인 매출 대시보드


  · 10주: 트랙 선택, 기획, 데이터 준비
  · 11주: 제작 + 상호 피드백
  · 12주: 발표회 — 링크를 가족·지인에게 실제로 전송하는 것까지가 커리큘럼


  [ 예산이 8주뿐이라면 ]


  3단계를 2주로 줄이고, 4단계를 1주 프로젝트 + 발표로 압축. 절대 줄이면 안
  되는 건 5주차(에러 대응)와 12주차(발표회) 입니다.


  [ 운영 조정 사항 ]


  · 조교 비율 완화 가능: 10~12명당 1명
  · 속도를 올리세요: 이 층에 가장 위험한 건 지루함입니다
  · "왜 이렇게 되는지"를 조금은 설명: 사무직 출신은 원리를 궁금해합니다. 다만
    5분 이내
  · 각자 자기 데이터를 매주 가져오게 — 숙제가 아니라 "재료 지참"으로 프레이밍
  · 결과물 아카이브 페이지를 만들어 매주 링크를 쌓아두기


  [ 미리 감안할 것 ]


  · 1주차 엑셀 실습에서 강사가 밀릴 수 있습니다. "제가 알려드린다"가 아니라
    "여러분 실력에 AI를 붙이면"으로 가야 안전합니다
  · 트랙별 강사 역량이 갈립니다. 자산관리 트랙은 연금·세금 질문이 쏟아지는데,
    "AI 답변은 반드시 전문가 확인"을 명시하지 않으면 책임 문제가 생깁니다
  · 개인 데이터 실습의 개인정보 리스크 — 7주차 시작 전에 규칙을 먼저 정해야
    합니다
  · 도구 유료 계정 비용과 사용량 한도는 4~9주차에 반드시 걸립니다

  [ 조사 결과 — 방향은 맞습니다 ]


  7개 기관(서울시50플러스재단, 서대문50플러스센터, 대전중장년지원센터, 용인시,
  KMA, 과기정통부 AI디지털배움터, 민간 국비학원)을 조사했습니다.

  이미 국내에서 검증된 것

  · 실습 중심 구성 — 조사한 모든 기관이 명시, 예외 없음
  · "말로 앱 만들기"는 이미 정규 과정입니다. 서대문50플러스센터가 「AI 바이브
    코딩 입문 — 말로 앱을 만드는 프로그래밍 입문 과정」을 운영 중입니다.
    실험적 시도가 아닙니다
  · 최종 회차 = 발표회. 서울시50플러스재단 과정들의 4회차가 "성과
    발표회·시상·수료"로 고정 편성돼 있습니다
  · 데이터 분석을 후반부에 배치 — 국내도 '고급' 단계로 분류

  국내에서 배워 반영해야 할 것 (이전 답변에서 놓친 부분)

  ▌ 조교를 동년배 또는 앞 기수 수료생 에서 뽑으십시오. 서울시50플러스재단은
  ▌ 시니어 강사 5명을 별도 선발했고, 과기정통부는 노노(老老)교육 보조강사
  ▌ 제도를 공식 운영합니다. 두 기관이 독립적으로 같은 결론에 도달했다는 건
  ▌ 취향 문제가 아니라는 뜻입니다.

  본 계획이 국내보다 앞선 지점 = 미검증 리스크

  · 개인 실데이터 사용 (국내는 예제 데이터 위주 — 개인정보 부담 때문으로 보임)
  · 한 과정 안에서의 트랙 분기 (국내는 과정 자체를 분리 개설)

  주의할 점: 국내 공공과정 표준은 12~18시간, 4~6주 입니다. 24시간/12주는
  최장급이라 예산·이탈 양쪽에서 부담이 큽니다. 8주 축약안을 문서에 함께
  넣었습니다.


  [ 조사의 한계 ]


  각 기관의 회차별 상세 커리큘럼은 대부분 비공개 여서, 서울시50플러스재단 2개
  과정만 실제 회차 구성을 확보했습니다. 그리고 중도이탈률·만족도를 공개하는
  기관이 하나도 없었습니다. 따라서 문서의 이탈 위험 곡선은 공개된 정량
  데이터가 아니라 대상층 특성 추론에 기반한 것입니다.

  요청하신 대로 정리했는데, 수강생 커리큘럼이 아니라 강사·운영진 도구로만
  배치했습니다(유인물·평가표·수료증 자동 생성). 이걸 수업에 넣으면 난이도가

  1. CSS 캐스케이드 충돌로 본문이 186px로 눌림
  ────────────────────────────────────────────


    .main{ grid-template-columns:1fr }
    @media(min-width:1000px){
      .main{ grid-template-columns:186px 1fr }
      .toc{ display:block }
    }
    .toc{ display:none; ... }   /* ← 미디어쿼리보다 뒤에 있어 동일 명시도로 덮어씀 */


  목차가 영영 display:none이 되었는데 그리드 열은 186px 1fr로 유지되어,
  목차가 사라진 자리에 본문이 들어가 186px 폭으로 눌렸습니다.
  .toc 기본 선언을 미디어쿼리 앞으로 옮겨 해결.


  2. CSS 클래스의 fill이 presentation attribute를 덮어씀 (74건)
  ─────────────────────────────────────────────────────────────


    <style>.svg-num{ fill:var(--ink-mute) }</style>
    <text class="svg-num" fill="var(--ochre)">24시간</text>   <!-- ochre가 무시됨 -->


  presentation attribute는 author CSS보다 우선순위가 낮습니다.
  12개 삽화 전체의 강조색 지정이 전부 무시되고 있었습니다.
  최소 예제(초록 CSS vs 빨강 속성)로 확인한 뒤, 74건을 인라인
  style="fill:..."로 승격시켜 해결.


  3. .figbox svg 선택자가 경고 아이콘까지 잡음
  ────────────────────────────────────────────


    .figbox svg{ min-width:600px; width:100% }


  경고 박스 안의 20px 아이콘이 이 규칙에 걸려 600px로 부풀고 본문이 오른쪽으로
  밀렸습니다.
  .figbox > svg로 직계 자식 한정하여 해결.


  4. 다크 테마에서 채도 높은 배경 위 흰 글씨가 안 읽힘
  ────────────────────────────────────────────────────


  라이트 모드의 황토색(#B5742A) 위 흰 글씨는 괜찮지만,
  다크 모드의 밝은 황토색(#DDA05A) 위 흰 글씨는 대비가 무너집니다.
  --on-accent 토큰을 분리(라이트 #FFFFFF / 다크 #12171C)하여 해결.


  5. 키노트 반전 슬라이드에서 HUD 색이 반대
  ─────────────────────────────────────────


  흰 배경 슬라이드에서 슬라이드 번호를 밝은 회색으로 지정해 보이지 않았습니다.
  픽셀값으로 확인(수정 전 (200,200,205) → 수정 후 (144,144,149))하고 해결.

  이 과정 설계의 핵심 주장 다섯 가지
  ──────────────────────────────────


  1. 첫 30분 안에 자기 결과물이 화면에 떠야 한다. 개념부터 가르치면 3주차에
     절반이 빠진다.
  2. 사무직 경력자에게는 엑셀이 관문이다. 국내 공공과정이 '중급'에 두는 것을
     1주차로 앞당겨야 신뢰를 얻는다.
  3. 에러 대응은 정식 교과다. 에러를 만나기 전에 에러 다루는 법을 먼저
     가르치는 것이 완주율을 결정한다.
  4. 조교는 동년배여야 한다. 서울시50플러스재단과 과기정통부가 각자 독립적으로
     같은 결론에 도달했다.
  5. 발표회에서 가족에게 링크를 보내는 것까지가 커리큘럼이다. 그 한 장면이
     다음 기수를 채운다.


  남아 있는 미검증 지점
  ─────────────────────


  · 개인 실데이터 사용 — 국내 사례는 예제 데이터 위주. 개인정보 관리 부담이
    실제로 어느 정도인지 확인되지 않음
  · 한 과정 내 트랙 분기 — 국내는 과정 자체를 분리 개설. 선례 없음
  · 총 24시간 / 12주 — 국내 공공 표준(12~18시간)을 상회. 이탈률에 미치는 영향
    미확인
  · 이탈 위험 곡선 전체 — 국내 어느 기관도 중도이탈률을 공개하지 않아, 설계자
    추론에 기반

  ▌ 마지막 항목이 이 문서 전체에서 가장 중요한 단서입니다.
  ▌ 실제 운영 시 회차별 출석을 기록해 추정 곡선을 실측치로 교체하는 것 이 다음
  ▌ 기수 설계의 출발점이 됩니다.
