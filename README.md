# 두 번째 명함

은퇴·은퇴예정 **사무직**을 대상으로 한 12주 AI 활용 실무 과정 강의계획서입니다.
전문 개발자 양성이 아니라, **"만들어 본 사람"을 배출하는 것**을 목표로 설계했습니다.

📄 **[강의계획서 보기 →](https://heekeunlee.github.io/for_senior/)**

---

## 이 과정이 무엇인가

| | |
|---|---|
| **대상** | 은퇴했거나 은퇴를 앞둔 사무직. 엑셀·문서·이메일에 익숙하고 생성형 AI 경험은 거의 없음 |
| **분량** | 12주 × 주 1회 2시간 = 총 24시간 |
| **정원** | 20명 (조교 2명, 10:1) |
| **도달 목표** | 말로 지시해 웹앱을 만들고, 자기 데이터로 대시보드를 만들고, 결과물 링크를 공유할 수 있다 |
| **환경** | 전 과정 브라우저 기반. 설치·터미널·개발환경 없음 |

### 4단계 구조

```
1단계 (1–3주)   즉시 효용        →  "내 엑셀 문제가 풀렸다"
2단계 (4–6주)   말로 앱 만들기    →  "내 앱이 생겼다"
3단계 (7–9주)   데이터·대시보드   →  "내 데이터가 그림이 됐다"
4단계 (10–12주) 트랙별 프로젝트   →  "내 이름의 결과물"
```

10주차에 **제2커리어 / 자산관리 / 기록·유산 / 모임·창업** 네 트랙으로 분기합니다.

## 국내 사례 대조 검증

계획을 세운 뒤, 정부·지자체·공공재단·민간에서 **실제로 운영 중인** 중장년·시니어 AI 교육과정을
조사해 방향이 어긋나지 않는지 확인했습니다 (2026년 8월 기준).

**검증된 것 —** 실습 중심 구성, 말로 앱 만들기(바이브 코딩), 최종 회차 발표회,
데이터 분석의 후반부 배치는 모두 국내 공공기관에서 이미 운영 중인 방식입니다.

**국내에서 배워 반영한 것 —** 동년배 조교 제도.
서울시50플러스재단은 시니어 강사를 별도 선발하고, 과기정통부는 노노(老老)교육 보조강사 제도를 운영합니다.

**본 과정 고유이자 미검증 —** 개인 실데이터 사용, 한 과정 내 트랙 분기.

자세한 내용은 [`docs/benchmark.md`](docs/benchmark.md) 참고.

### ⚠️ 무엇이 사실이고 무엇이 판단인가

문서 전체에 근거 등급을 배지로 표시했습니다.

- **`실측`** — 공개된 운영 자료에서 확인한 사실 (기관별 구성·분량·정원·비용)
- **`추정`** — 대상층 특성에 근거한 설계자 판단

**주차별 이탈 위험도 곡선, 리스크 영향도, 대상 프로필은 모두 「추정」입니다.**
국내 어느 기관도 중도이탈률이나 만족도를 공개하지 않기 때문입니다.
해당 도표에는 경고 박스를 붙였고 세로축 눈금을 의도적으로 뺐습니다 —
봉우리의 순서와 상대적 크기만 참고하시고, 절대 수치로 인용하지 마십시오.

## 저장소 구성

```
index.html          배포되는 강의계획서 (자동 생성 — 직접 수정하지 말 것)
src/syllabus.html   ← 실제 원본. 내용 수정은 여기서
build.sh            src → index.html 빌드
docs/
  benchmark.md      국내 운영 사례 조사 결과
  curriculum.md     12주 커리큘럼 텍스트판
```

### 수정하는 법

```bash
# 1. src/syllabus.html 편집
# 2. 빌드
./build.sh
# 3. 커밋
git add -A && git commit -m "..." && git push
```

`index.html`은 `src/syllabus.html`에서 생성됩니다. `index.html`을 직접 고치면 다음 빌드에서 덮어써집니다.

- 12주 주차별 커리큘럼 (매주 손에 남는 결과물 명시)

- 개인 데이터 취급 규칙, 리스크 등록부 8종
